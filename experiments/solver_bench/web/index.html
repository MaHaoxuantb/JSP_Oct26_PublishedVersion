EXPERIMENT CONTRACT
How to read this experiment
Eight conditions
Discrete / continuous × regional off / on × new branch pruning off / on. All share the same framework and matched seeds.
What counts as solved
A connected, symmetric partition satisfying every clue under integer shortest-path costs, checked again by an independent Python evaluator.
What “unique” means
One canonical partition after exhaustive search. A partial search never proves uniqueness. Up to three proven partitions may qualify at the preparation deadline.
Shape coverage
The permanent cache is a speed aid. Exact lazy enumeration covers uncached shapes up to the full board size. Cache generation progress is not full shape-domain completion.
Compute budget
Four synchronous CPU searches, one hot thread each; no GPU. macOS does not guarantee physical P-core pinning. CPU time, wall time, memory and resource anomalies are recorded.
Unsolved runs
Time limits are right-censored at 1,200 seconds. Failures, pending trials and interruptions remain separate from timeouts.
Completed measurements by condition
Capped cost includes unsolved trials at 1,200 seconds. It does not predict eventual solving time. Small samples are descriptive; historical experiments are excluded.
